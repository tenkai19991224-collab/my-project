# サムネイル横伸び修正 — 「何もしたくない　それ統合の前兆です」

## 何が起きていたか

元ファイル自体は 1280x720（YouTube推奨の16:9）で、画像全体が伸びていたわけではない。
伸びていたのは **文字レイヤーだけ**。

計測結果（漢字の字面は本来ほぼ正方形になる）:

| 対象 | 字面の 幅/高さ | 判定 |
|---|---|---|
| 何（1行目・白） | 0.98 | 正常 |
| 統（2行目・金） | 1.30 | 約30%横伸び |
| 合（2行目・金） | 1.23 | 約25%横伸び |
| 前（3行目・白） | 1.18 | 約20%横伸び |
| 兆（3行目・白） | 1.23 | 約25%横伸び |

装飾フレームの内側余白は上下左右ほぼ均一（横19.5px / 縦21.0px）で、
背景とフレームは歪んでいない。つまり原因は画像全体の拡大ではなく、
**テキストを角ハンドルではなく横ハンドルで引き伸ばした**こと。
1行目は7文字あって元から幅が埋まるため伸ばす必要がなく、無傷だった。

## 修正内容

`unstretch_text.py` が行う処理:

1. 文字の縁取り色（暗い臙脂）から全テキストのマスクを生成
2. 2行目・3行目の文字を行ごとに分離
3. 文字の下の背景を拡散フィルで再構成し、**距離マップによる34pxのフェザー**で
   元の背景へなだらかに繋ぐ（境界が出ないので再構成跡が残らない）
4. 各行を横 1/k に圧縮しつつ、露出する背景を減らすため全体を少し拡大
   （2行目 k=1.30 / s=1.12、3行目 k=1.25 / s=1.07）
5. 元の輝きを一緒に運ぶソフトアルファで合成

結果、統 の字面は 314x241 (1.30) から 269x269 (1.000) になり正方形に戻った。
1行目と装飾フレームは一切触れていない。

## 背景の再構成跡について

初版は硬い境界のマスクで背景を差し替えていたため、2行目の左右に平坦な
パッチが見えていた。距離マップによるフェザー合成に変更して解消済み。
雲・光の粒・花びらはいずれも元のまま残っている。

なお、これは書き出し済みJPEGに対する後処理であることに変わりはない。
元データ（Canva等のプロジェクト）が残っているなら、そちらで文字を
角ハンドル基準で組み直して書き出す方が根本的。
